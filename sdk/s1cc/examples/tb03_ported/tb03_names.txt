# tb03_names.txt: names for the lifted TB-03 voice (dsplift.py --names, README.md §2). Hand-written: what is known of
# the program is written here, tb03_voice.h is regenerated (tools/make_voice.sh).
#
#   param ADDR NAME [knob]   a parameter word; knob = set by the panel (tb03.c). The other parameters are the TB-03
#                            init's values (tb03_tables.h tb03_init): make_voice.sh hands them to dsplift as constants
#   in / out ADDR NAME       bank-5 inputs / outputs
#   unused ADDR...           outputs tb03.c's KOUT ignores
#   const ADDR[-ADDR] VALUE  inputs that are constants in tb03.c (tb03_in)
#   cell X NAME              the value stored in bank-0 cell X
#   value K rN NAME          the value register rN holds after instruction K
#   section K TEXT           a heading above the values from instruction K on
