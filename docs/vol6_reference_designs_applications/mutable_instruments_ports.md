## 4.1 Overview of Mutable Instruments Porting Project

The Mutable Instruments porting collection (`sdk/s1cc/examples/mutable_ported/` and `examples/mutable_system/`) brings landmark open-source Eurorack synthesis models (from Émilie Gillet's **Braids** and **Plaits**) to the Roland BMC DSP architecture.

By employing the `mport` fixed-to-floating point compilation passes and polynomial LUT fitting, these computationally intensive physical modeling and oscillator algorithms run with real-time polyphony at 96 kHz:


## 4.2 Engine Analysis & Benchmarks

### 4.2.1 `CSAW` (CS-80 Dual Sawtooth Oscillator) `[VERIFIED]`
- **Acoustic Model**: Simulates the dual-sawtooth oscillator core of the Yamaha CS-80, incorporating a continuous notch filter whose width and position are modulated by the COLOR knob.
- **Polyphony**: Full **8 polyphonic voices** on SYSTEM-1 and SYSTEM-8.
- **Cycle Footprint**: 512 / 703 cycles on DSP A; 420 / 708 cycles on DSP B.

### 4.2.2 `SAW_SWARM` (7-Voice Detuned Super-Saw) `[MEASURED]`
- **Acoustic Model**: Roland JP-8000 style Super-Saw generated by 7 free-running phase accumulators with prime-ratio frequency detunings.
- **Polyphony**: **6 polyphonic voices** on SYSTEM-1.
- **Optimization**: Phase updates are scheduled in parallel using 4 dual-product MACs and packed `ph_wrap` operators.

### 4.2.3 `BELL` (Inharmonic Additive Synthesis) `[VERIFIED]`
- **Acoustic Model**: Computes 6 inharmonic sinusoidal partials with exponential amplitude decay envelopes modeling struck metallic bars and tubular bells.
- **Polyphony**: Full **8 polyphonic voices** on SYSTEM-1.
- **Cycle Footprint**: 490 cycles on DSP A.

## 4.3 Pipelined PolyBLEP Anti-Aliased Oscillator Kernel

To eliminate digital aliasing across high-frequency sawtooth transients, the clean-room kernel implements polynomial Band-Limited Step (PolyBLEP) correction in microcode:

$$y_{\text{blep}}(t) = 
\begin{cases} 
2t - t^2 - 1.0 & 0 \le t < 1.0 \\
t^2 + 2t + 1.0 & -1.0 < t < 0 \\
0.0 & \text{otherwise}
\end{cases}$$

```dsp
; PolyBLEP Anti-Aliasing Correction Kernel
ld r1, [0301]      ; Load accumulated phase
mov r4, r4         ; Delay slot
addxy r1, r1, r2   ; Advance phase by delta r2
ph_wrap r1, r3, r1 ; Wrap to [-1.0, +1.0)
st r1, [0300]      ; Store phase

; Compute PolyBLEP Boundary Correction
absadd r5, r1, #0.0 ; r5 <- |phase|
mov r6, #1.0
subxy r7, r5, r6   ; r7 <- 1.0 - |phase|
mul r0, r7, r7     ; r0 <- (1.0 - |phase|)^2
```
