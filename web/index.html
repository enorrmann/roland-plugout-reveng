PLUG-OUT installer SYSTEM-8 / SYSTEM-1

Puts a PLUG-OUT into a slot of a Roland SYSTEM-8 or SYSTEM-1 over USB. Everything happens in this page: no plug-in, no driver, no command line.

1Web MIDI with SysEx Checking…

The page talks to the synth with Web MIDI + SysEx. It needs Chrome, Edge or another Chromium browser, opened from http://localhost or https://.

2Connect the synth Waiting

Connect the synth to this computer with a USB cable and switch it on. The page finds it by itself; nothing to choose. Close other programs that use the synth's MIDI first.

Advanced: another MIDI port

The synth has two USB MIDI ports. The installer needs the control port (… 2 or CTRL), which the page picks by itself. Change it only if the synth is connected through another interface.

3Choose the slot Waiting

The slot you pick is filled completely: whatever is in it now is overwritten. On a SYSTEM-8 the slot also decides which file you need next.

4The firmware file Waiting

Choose the file Code1.Dat from the Script folder of the plug-in, or drop it on this card. Only a file with exactly this name is taken. The file stays in this browser; nothing is uploaded.
